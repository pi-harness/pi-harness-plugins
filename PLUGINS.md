# Plugin directory

The repository contains the following published packages:

- [`@pi-harness/plugin-agent-teams`](packages/plugins/agent-teams/README.md) — Maintain a bounded, session-local collaboration ledger of named roles, dependency-aware tasks, and mailbox notes without spawning agents or sending external messages. 
- [`@pi-harness/plugin-anchored-standard`](packages/plugins/anchored-standard/README.md) — Audit agent trajectories against an explicit tool-call allowlist and flag activity outside the anchored run. 
- [`@pi-harness/plugin-annotation`](packages/plugins/annotation/README.md) — Capture bounded selections and notes from the conversation for later agent context. 
- [`@pi-harness/plugin-archify`](packages/plugins/archify/README.md) — Build a bounded, read-only architecture map from workspace components and package dependencies. 
- [`@pi-harness/plugin-at-file`](packages/plugins/at-file/README.md) — Attach a bounded 256 KiB strict UTF-8 workspace file using canonical workspace path confinement and no-follow regular-file reads, framing it as offline, read-only, untrusted model context with closing-tag neutralization and cancellable sequential execution. 
- [`@pi-harness/plugin-auto-mode`](packages/plugins/auto-mode/README.md) — Execute argv commands under a safe policy that blocks shell wrappers and requires confirmation for risky operations. 
- [`@pi-harness/plugin-better-sidebar`](packages/plugins/better-sidebar/README.md) — Show a compact workspace, Git, and session overview beside the conversation without modifying files. 
- [`@pi-harness/plugin-browser-fetch`](packages/plugins/browser-fetch/README.md) — Fetch public HTTP and HTTPS pages as bounded text with descriptor-safe inputs, DNS pinning, per-redirect private-network validation, textual MIME enforcement, cancellation, a whole-request timeout, and validated fail-closed panel reporting. 
- [`@pi-harness/plugin-browser-session`](packages/plugins/browser-session/README.md) — Control a loopback-only Chrome DevTools session with descriptor-safe commands, bounded discovery, cancellable operations, screenshot metadata protection, and validated fail-closed panel previews. 
- [`@pi-harness/plugin-canvas-draw`](packages/plugins/canvas-draw/README.md) — Generate validated, bounded Mermaid flowchart source from structured nodes and edges in the workspace UI. 
- [`@pi-harness/plugin-change-verifier`](packages/plugins/change-verifier/README.md) — Combine project tests and Git change review into one explicit verification gate before handoff. 
- [`@pi-harness/plugin-cleaner`](packages/plugins/cleaner/README.md) — Strict descriptor-safe configuration and parameters, display-safe bounded Pi Harness Git capsule inventory, removal with explicit confirmation and retention controls, symlink and replacement defenses, cancellable serialization, and a fail-closed normalized panel. 
- [`@pi-harness/plugin-cli-notifier`](packages/plugins/cli-notifier/README.md) — Send local desktop notifications when an agent turn completes, fails, or is aborted, and when context compaction fails. 
- [`@pi-harness/plugin-code2skill`](packages/plugins/code2skill/README.md) — Package selected workspace source files into a bounded local Pi skill with a generated SKILL.md manifest and preserved references. 
- [`@pi-harness/plugin-colleague-skill`](packages/plugins/colleague-skill/README.md) — Create durable, structured handoff packets for another role without hidden agents or external message delivery. 
- [`@pi-harness/plugin-context-doctor`](packages/plugins/context-doctor/README.md) — Descriptor-safe bounded context audits detect pressure, oversized or uninspectable messages, and tool errors. Compaction requests are queued until the agent has settled; confirmed model-backed compaction may incur cost and provides cancellable waits with dedicated cancellation. 
- [`@pi-harness/plugin-context`](packages/plugins/context/README.md) — Inspect context usage and descriptor-safe bounded message composition with cached active-session lifecycle counters and a fixed-limit normalized browser panel. 
- [`@pi-harness/plugin-cost-meter`](packages/plugins/cost-meter/README.md) — Track runtime-reported costs as UTC daily increments in a bounded local ledger, with session snapshots and optional daily budget monitoring; no model prices are guessed. 
- [`@pi-harness/plugin-dependency-checker`](packages/plugins/dependency-checker/README.md) — Run a bounded, offline, read-only check of workspace package.json and requirements*.txt manifests for local package presence, duplicate declaration consistency, unresolved constraints, and unsupported Python directives. 
- [`@pi-harness/plugin-docker-sandbox`](packages/plugins/docker-sandbox/README.md) — Run descriptor-safe argv commands with local-only Docker images, no container network, a read-only workspace by default, fixed CPU, memory, and PID limits, sanitized output, strict panel reporting, and cancellation cleanup. 
- [`@pi-harness/plugin-fail-logger`](packages/plugins/fail-logger/README.md) — Aggregate bounded extension, Agent, and non-aborted compaction failures through descriptor-safe event inspection, safe diagnostic summaries, and occurrence counts without retaining full payloads. 
- [`@pi-harness/plugin-genui`](packages/plugins/genui/README.md) — Render bounded structured cards with text, badge, and decimal progress blocks while displaying HTML and scripts as plain text. 
- [`@pi-harness/plugin-git-time-capsule`](packages/plugins/git-time-capsule/README.md) — Capture the current unstaged tracked Git diff as a byte-exact, validated undo capsule without external diff or textconv helpers, then reverse-apply it only after explicit confirmation. 
- [`@pi-harness/plugin-graph-memory`](packages/plugins/graph-memory/README.md) — Store bounded typed task, skill, and event nodes with validated directed relations, atomic locked persistence, and inspectable cross-session search. 
- [`@pi-harness/plugin-history-compressor`](packages/plugins/history-compressor/README.md) — Compact the current Pi session automatically when context usage approaches a configured threshold. 
- [`@pi-harness/plugin-hol-guard`](packages/plugins/hol-guard/README.md) — Audit tool arguments and preflight text for destructive commands, sensitive paths, credentials, and remote exfiltration. Advisory only: reports risk, does not block execution. 
- [`@pi-harness/plugin-i18n-pair`](packages/plugins/i18n-pair/README.md) — Strict read-only comparison of bounded JSON locale files from no-follow workspace paths, with collision-safe missing and extra keys, stable failures, cancellation, and validated panel status. 
- [`@pi-harness/plugin-image-compressor`](packages/plugins/image-compressor/README.md) — Create bounded image copies for model context while preserving the original file and reporting saved bytes. 
- [`@pi-harness/plugin-llm-verifier`](packages/plugins/llm-verifier/README.md) — Ask a configured verifier model to judge a claim against bounded, untrusted evidence. 
- [`@pi-harness/plugin-mcp-client`](packages/plugins/mcp-client/README.md) — Connect to direct-argv MCP stdio servers with bounded pagination and protocol validation, tool, resource, and prompt bridging, cancellable queued requests, and lifecycle-owned process cleanup. 
- [`@pi-harness/plugin-mcp-panel`](packages/plugins/mcp-panel/README.md) — Inspect MCP server health and tools, preview profile patches, and apply changes only with an explicit confirmation and backup. 
- [`@pi-harness/plugin-memory`](packages/plugins/memory/README.md) — Persist bounded cross-session notes with explicit recall and update operations. 
- [`@pi-harness/plugin-mirage-bridge`](packages/plugins/mirage-bridge/README.md) — Connect Pi Harness to the official Mirage virtual-terminal CLI without adding a second host shell. 
- [`@pi-harness/plugin-mock-server`](packages/plugins/mock-server/README.md) — Start a local, bounded HTTP mock server from explicit routes for integration testing without external services. 
- [`@pi-harness/plugin-modlens`](packages/plugins/modlens/README.md) — Send bounded workspace images to native vision models or return schema-validated evidence from the bundled ModLens engine for text-only models. 
- [`@pi-harness/plugin-module-search`](packages/plugins/module-search/README.md) — Find imports, exports, and declared symbols in bounded workspace source files without modifying them. 
- [`@pi-harness/plugin-obsidian-sync`](packages/plugins/obsidian-sync/README.md) — Write explicitly requested session notes to a bounded Obsidian vault path without reading unrelated vault files. 
- [`@pi-harness/plugin-openpets`](packages/plugins/openpets/README.md) — Keep a bounded durable companion state from validated recent session entries without retaining message contents, with descriptor-safe actions and explicit persistence health. 
- [`@pi-harness/plugin-plan-execute`](packages/plugins/plan-execute/README.md) — Track an explicit multi-step execution plan with progress, dependencies, and completion state in the current session. 
- [`@pi-harness/plugin-plugin-check`](packages/plugins/plugin-check/README.md) — Inspect installed plugin manifests and report unsafe, malformed, or incompatible extension metadata before loading it. 
- [`@pi-harness/plugin-plugin-dev`](packages/plugins/plugin-dev/README.md) — Defer Pi session resource reloads until the agent is settled, enforce a single active reload with bounded status, and expose the operation only for trusted local development. 
- [`@pi-harness/plugin-plugin-finder`](packages/plugins/plugin-finder/README.md) — Search a configured npm-compatible registry for Pi plugins with bounded queries and explicit installation handoff. 
- [`@pi-harness/plugin-plugin-radar`](packages/plugins/plugin-radar/README.md) — Discover public Pi Harness repositories on GitHub, sorted by stars. 
- [`@pi-harness/plugin-plugin-stars`](packages/plugins/plugin-stars/README.md) — Search a curated raw.githubusercontent.com plugin snapshot through descriptor-safe inputs, strict bounded validation, a cancellable lifecycle, and fail-closed panel reporting. 
- [`@pi-harness/plugin-prompt-guard`](packages/plugins/prompt-guard/README.md) — Detect prompt override, secret exfiltration, remote payloads, and hidden-instruction indicators without retaining input text. 
- [`@pi-harness/plugin-prompt-library`](packages/plugins/prompt-library/README.md) — Save, search, update, and delete reusable prompt templates in the current Pi session. 
- [`@pi-harness/plugin-readme-gen`](packages/plugins/readme-gen/README.md) — Generate README reports from strictly bounded manifest metadata and a descriptor-safe loader inventory with Markdown-safe rendering, plus confirmed no-clobber atomic writes, explicit overwrite confirmation, and cancellable sequential execution. 
- [`@pi-harness/plugin-recall-unread`](packages/plugins/recall-unread/README.md) — Read-only bounded discovery with strict UTF-8 session reads finds current workspace conversations ending in an unanswered user message, uses cached startup inventory, and rescans only on explicit tool calls. 
- [`@pi-harness/plugin-reverse-skill`](packages/plugins/reverse-skill/README.md) — Inspect untrusted Skill text and inject it only through an explicit bounded data boundary. 
- [`@pi-harness/plugin-reviewer-bot`](packages/plugins/reviewer-bot/README.md) — Review tracked Git changes against HEAD for whitespace, likely credentials, and TODO/FIXME markers without executing diff helpers. 
- [`@pi-harness/plugin-runtime-doctor`](packages/plugins/runtime-doctor/README.md) — Audit workspace, agent directory, model, runtime, MCP servers, and extension errors in one read-only report. 
- [`@pi-harness/plugin-secure-audit`](packages/plugins/secure-audit/README.md) — Read-only workspace scan for exposed credentials and dangerous shell commands with value-redacted findings. 
- [`@pi-harness/plugin-session-bookmarks`](packages/plugins/session-bookmarks/README.md) — Persist labels for important native Pi session entries without changing the underlying transcript. 
- [`@pi-harness/plugin-session-bridge`](packages/plugins/session-bridge/README.md) — Preview and export handoffs, then require confirmed import of a strictly validated, bounded package into the active LLM context with duplicate protection. 
- [`@pi-harness/plugin-session-compare`](packages/plugins/session-compare/README.md) — Compare two persisted Pi sessions by message role and text without modifying either session file. 
- [`@pi-harness/plugin-session-export`](packages/plugins/session-export/README.md) — Export the current Pi conversation to a bounded Markdown file inside the workspace without changing session history. 
- [`@pi-harness/plugin-session-insights`](packages/plugins/session-insights/README.md) — Publish descriptor-safe validated cached session statistics and run only confirmed settled-session compaction with explicit model usage and cost guidance plus cancellable lifecycle handling. 
- [`@pi-harness/plugin-session-search`](packages/plugins/session-search/README.md) — Search persisted Pi JSONL sessions for matching user or assistant text without modifying session files. 
- [`@pi-harness/plugin-skill-catalog`](packages/plugins/skill-catalog/README.md) — List loaded Agent Skills and safely inspect one through a bounded untrusted-data boundary, plus managed MCP status. 
- [`@pi-harness/plugin-skill-guard`](packages/plugins/skill-guard/README.md) — Audit each loaded Skill entry Markdown file with bounded heuristics for instruction override, secret exfiltration, destructive commands, and obfuscation; it reports risk labels and does not disable loaded Skills. 
- [`@pi-harness/plugin-sql-lens`](packages/plugins/sql-lens/README.md) — Inspect workspace-contained SQLite databases with strict descriptor-safe inputs, a single read-only statement, bounded results, symlink and replacement checks, timed worker execution, cancellation, and fail-closed panel reporting. 
- [`@pi-harness/plugin-synapse`](packages/plugins/synapse/README.md) — Visualize session relationships and linked work items without changing the transcript. 
- [`@pi-harness/plugin-tab-manager`](packages/plugins/tab-manager/README.md) — Organize active Pi sessions into named tabs and switch between them without losing session identity. 
- [`@pi-harness/plugin-taskboard`](packages/plugins/taskboard/README.md) — Track agent tasks, statuses, and dependencies in a durable project board. 
- [`@pi-harness/plugin-telemetry-blocker`](packages/plugins/telemetry-blocker/README.md) — Block configured outbound telemetry destinations and report blocked attempts without collecting payload contents. 
- [`@pi-harness/plugin-test-harness`](packages/plugins/test-harness/README.md) — Run five fixed npm script names from a trusted workspace, reporting real status with a sanitized 12 KiB UTF-8-safe untrusted output tail, a bounded configurable timeout, and cancellable process-tree cleanup. 
- [`@pi-harness/plugin-theme-studio`](packages/plugins/theme-studio/README.md) — Apply bounded Light, Midnight, Paper, and High Contrast presets to the Pi Harness web surface. 
- [`@pi-harness/plugin-token-guard`](packages/plugins/token-guard/README.md) — Use descriptor-safe monitoring to issue at most one abort request per run when a context percentage or SDK-reported run-token budget is reached, with bounded errors and a cached normalized panel. 
- [`@pi-harness/plugin-turn-rewind`](packages/plugins/turn-rewind/README.md) — Scans a bounded current branch for user turns, supports queued serialized cancellable rewinds after the agent settles, and navigates the native session tree while preserving abandoned branches. 
- [`@pi-harness/plugin-undo-savepoint`](packages/plugins/undo-savepoint/README.md) — Create inspectable savepoints before agent changes so the workspace can be restored safely. 
- [`@pi-harness/plugin-vision-toolkit`](packages/plugins/vision-toolkit/README.md) — Catalog signature-verified PNG, JPEG, GIF, and WebP metadata with bounded header reads, cancellable workspace traversal, explicit partial results, and a local-only normalized panel. 
- [`@pi-harness/plugin-web-research`](packages/plugins/web-research/README.md) — Search the public web through a configurable provider and return bounded, cited source evidence. 
- [`@pi-harness/plugin-workspace-navigator`](packages/plugins/workspace-navigator/README.md) — Show a bounded workspace tree and read-only Git status for a high-signal coding sidebar. 
- [`@pi-harness/plugin-workspace-search`](packages/plugins/workspace-search/README.md) — Search bounded text files in the active workspace with ignored directories and binary content excluded. 
- [`@pi-harness/plugin-yaml-validator`](packages/plugins/yaml-validator/README.md) — Validate workspace-contained UTF-8 multi-document YAML through bounded, cancellable reads and line-aware diagnostics.
